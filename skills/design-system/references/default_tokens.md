# 기본 디자인 시스템 프리셋: Cool Stone & Royal Indigo (`80-15-5`)

프로젝트 오버라이드가 없을 때 기본으로 적용되는 밝은 토널 레이어 디자인 시스템이다. 모든 값은 단일 토큰 원본(`tokens.json`)에서 파생해 `:root` CSS 변수와 Tailwind 시맨틱 토큰에 1:1 연결한다.

## 1. 색 면적 법칙 (`80-15-5`) & 다크 강조 블록 스코프

- **기본 극성 (`:root`)**: 쿨 스톤 & 로열 인디고 단일 라이트 테마(`color-scheme: light`).
- **80% 바탕**: `canvas` (`#F8FAFC`) · `mist` (`#EEF2F6`)
- **15% 전경/다크**: `raised` (`#FFFFFF`) · `surface` (`#F1F5F9`) · `ink` (`#151B26`)
- **5% 단일 초점**: `brand-500` (`#254EDB`) — 뷰포트당 주 행동 1곳에만 집중.
- **다크 강조 블록 (`.hero--dark`, `[data-block="dark"]`, 폰 목업 등)**: 페이지 전체가 아닌 강조 섹션·목업 전용 스코프. 동일 시맨틱 CSS 변수를 `--c-raised: 30 38 54`, `--c-mist: 42 52 72`, `--c-fg: 248 250 252`, `--c-fg-2: 203 213 225`, `--c-fg-3: 148 163 184`, `--c-line: rgb(255 255 255 / 0.14)`, `--c-ink-accent: 147 180 255`로 재정의해 사용한다.

## 3. 타이포그래피 · 반경 · 그림자 · 모션 · 아이콘

- **글꼴**: `fontSans` = `Pretendard, -apple-system, BlinkMacSystemFont, system-ui, sans-serif` / `fontDisplay` = `"Space Grotesk", Pretendard, system-ui, sans-serif` (숫자·영어 인용·타이머). 정렬이 필요한 숫자는 `tabular-nums`를 쓴다.
- **7단 크기 스케일**:

| 토큰 | 크기 / 줄 간격 / 굵기 | 쓰는 곳 |
|---|---|---|
| `text-num-lg` | `28px` / `1.1` / `700` | 큰 숫자(타이머·핵심 지표) |
| `text-display` | `26px` / `1.3` / `700` (`-0.025em`) | 머리 제목(`Hero`, 완료/입장 제목) |
| `text-title` | `20px` / `1.35` / `700` (`-0.015em`) | 탭 화면 제목, 시트 질문 |
| `text-head` | `17px` / `1.4` / `600` | 섹션 제목, 하위 화면 제목, 금액 |
| `text-body` | `15px` / `1.55` | 본문, 목록 첫 줄, 말풍선 본문 |
| `text-meta` | `13px` / `1.45` | 목록 둘째 줄, 보조 설명 |
| `text-cap` | `12px` / `1.4` | 숫자 라벨, 탭 바 이름 |

- **가독·입력 하한선**: 폼 입력칸(`Input`·`Select`·`TextArea`)은 iOS 자동 확대를 막기 위해 `text-base`(`16px`) 이상을 쓴다. `text-2xs`(`11px`)·`text-3xs`(`10px`)는 법정 고지·범례·작은 `Badge`에만 제한하며, **마케팅 랜딩 첫 화면(폴드 위)에는 `13px`(`text-meta`) 미만 글자를 두지 않는다.**
- **반경 (`radius`)**: `rounded-hero`(`28px`), `rounded-card`(`24px`), `rounded-2xl`(`16px` 버튼·토스트·배너·중첩 카드), `rounded-xl`(`12px` 입력칸), `rounded-lg`(`8px` `Chip`), `rounded-full`(아바타·표식·스위치·알약 CTA).
- **그림자 (`shadow`)**:
  - `card`: `0 4px 24px -8px rgb(15 23 42 / 0.06)`
  - `cta`: `0 12px 28px -10px rgb(37 78 219 / 0.42)`
  - `heroAction`: `0 8px 30px -12px rgb(15 23 42 / 0.1), 0 0 0 1px rgb(226 232 240 / 0.8)`
  - `heroDark`: `0 12px 32px -12px rgb(21 27 38 / 0.28)`
- **모션 (`motion`)**: 누름·스위치·토스트 `150ms ease-out`, 시트·스티키 헤더·진행 막대 `200ms ease-out`, 다이얼로그 진입 `220ms`·퇴장 `300ms`. **`transition-all` 금지**, `prefers-reduced-motion: reduce` 준수.
- **아이콘 · 터치 표적**: 선 굵기 **`1.75`** 통일(목록 `20px`, 인라인 `16px`, 조작 `24px`). 모든 상호작용 컨트롤 높이·너비는 **`>= 44px`**.
