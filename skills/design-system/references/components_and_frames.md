# 화면 틀 3종 · 컴포넌트 문법 · 상태/접근성 패턴

의존성(무거운 UI 래퍼) 없이 얇고 일관된 시맨틱 부품으로 화면을 조립하기 위한 구조 표준이다.

## 1. 화면 틀 3가지 (`Screen`)

| 틀 | 쓰는 곳 | 상단 머리 | 하단 |
|---|---|---|---|
| **`TabScreen`** | 최상위 기본 탭 화면 | **비고정.** 왼쪽 `text-title` 제목(+ 부제), 오른쪽 설정 등 단일 아이콘 | 하단 `TabBar` 고정 |
| **`SubScreen`** | 상세·목록·설정 하위·약관·관리 | **고정(`sticky z-20`).** `←` + `text-head` 제목 + 오른쪽 단일 `action` | 필요 시 `TabBar`, 아니면 safe-area 여백 |
| **`TaskScreen`** | 집중 작업·입력·결제·온보딩·진행 | **고정(`sticky z-20`).** `✕` + 가운데 `title`/`center` + 오른쪽 `action`/`progress` | 탭 없음. `footer` 고정(주 버튼 1개) |

- **상단 고정·단일 행 규칙 (`SubScreen` · `Tabs sticky`)**: `Tabs sticky`가 붙은 화면은 아래로 스크롤(`>= 12px`)하면 헤더를 숨겨(`:not(:focus-within)`) 44px `Tabs` 한 줄만 남겨 모바일 뷰포트 점유율 12% 미만을 지킨다. 위로 스크롤(`>= 8px`)하거나 키보드 포커스가 들어가면 헤더를 복구한다.
- **중복 이탈 금지**: `TaskScreen` 상단에 `× 닫기`가 있으면 하단 `footer`에 같은 목적의 텍스트 `돌아가기` 링크를 중복 두지 않는다.

## 2. 핵심 컴포넌트 사용 문법 (유사성·전경 원칙)

기능이 다르면 시각 문법도 달라야 한다. 모든 섹션·카드·모달은 **눈썹 없이 제목(`h1`~`h3`)으로 바로 시작**한다.

| 구분 | 형태 | 언제 쓰나 (Do) | 언제 금지하나 (Don't) |
|---|---|---|---|
| **`Hero`** | `tone`: `action`(순백 `28px`) · `quiet`(`bg-mist`) · `dark`(`bg-ink`) | 화면 최상단 핵심 요약 + 주 행동 1개 | 눈썹 문구 추가, `Hero` 내 주 버튼 2개 이상 배치 |
| **`Section` · `RowList`** | `text-head` 제목(+ 우측 `link`) + 순백 `24px` 카드 목록 | 관련 항목 묶음, 설정·요약·타임라인(`Timeline`) | 카드 안에 또 그림자 있는 순백 카드 중첩, 섹션 상단 `1px` 선 중복 |
| **`PrimaryButton`** | `brand-500` 채움, 높이 `>= 48px`, `whitespace-nowrap` | **뷰포트당 가장 중요한 행동 오직 1개** | 보조·취소·다중 선택지에 사용 |
| **`Chip`** | `rounded-lg` 1px 테두리 + 채움/틴트 (`aria-pressed`, `>= 44px`) | **누를 수 있는 선택/필터/토글**에만 사용 | 누를 수 없는 상태 표시, 제목 위 라벨 |
| **`Badge`** | 테두리 없는 작은 `text-2xs font-semibold rounded-full` 알약 | **실시간 상태·판정·추천 요금제 태그**에만 사용 | **제목 위 눈썹 자리**, 장식용 정적 카드 알약, 본문 명사 반복, 클릭 유도 |
| **`StatusDot` / `Marker`** | `6~8px` 점 / `24px` 원 표식 | 범례·점 상태 / `Timeline`·순서 진행 표시 | 일반 목록 장식, 비순서 `01`/`02` 남발 |
| **`Switch`** | `role="switch"` (`44×26px`) | **즉시 저장·전환되는 이진 켜기/끄기** 설정 | 3개 이상 선택지, 확인이 필요한 파괴적 동작 |
| **`BottomSheet` / `ConfirmSheet`** | `rounded-3xl`, 모바일 바닥 시트 / 데스크톱(`>=640px`) 중앙 모달 | 짧은 선택·동작 목록·파괴적 확인(`DangerButton`) | `<640px` 모바일 중앙 모달, 네이티브 `window.alert`/`confirm` |

## 3. 상태 · 오류 · 확인 · 접근성 규칙

- **로딩 / 대기 (`Loading` / `WorkingState`)**: 화면 틀은 즉시 그리고, 본문만 뼈대(`Skeleton`, 0.3s 뒤 노출) 또는 진행 막대로 표시한다.
- **빈 상태 / 오류 (`EmptyState` / `ErrorState`)**: 제목 + 한 줄 설명 + 보조 버튼 1개. 오류는 **무슨 일 + 다음 행동**과 `[다시 시도]`를 함께 둔다.
- **인라인 오류 (`role="alert"`)**: 시트·카드 내부 오류는 시트를 닫지 않고 대상 버튼/입력칸 바로 아래 `text-meta text-danger-400` 1줄로 보여준다.
- **확인 · 되돌리기**: 되돌릴 수 있으면 즉시 실행 + 5초 `toast`(`[되돌리기]`), 돈·삭제·중단 같은 되돌릴 수 없는 작업만 `ConfirmSheet`(`DangerButton`)로 확인한다.
- **접근성 · 줄바꿈**: `360~390px` 모바일 가로 스크롤 0건(`scrollWidth <= innerWidth`), 포커스 링 2px 유지, 다중 줄 한국어 `break-keep`, 표 헤더·가격 묶음 `whitespace-nowrap`, `tabular-nums`.
